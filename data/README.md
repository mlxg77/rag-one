# 星云科技员工手册：RAG 入门数据集

这是一套完全虚构的中文员工手册，用于学习和测试检索增强生成（RAG）。公司、人员、制度和金额均为模拟信息，不能作为真实劳动或财务制度依据。

## 数据集内容

- `knowledge_base/`：10 个 Markdown 知识库文件
- `eval/questions.jsonl`：25 条评估问题，包含期望答案、来源和问题类型

## 推荐用法

1. 将 `knowledge_base/` 下的文件放进项目的 `data/raw/`。
2. 第一轮使用 `chunk_size=600`、`chunk_overlap=100`、`top_k=5`。
3. 建立索引后，用 `eval/questions.jsonl` 逐条测试。
4. 调试时同时输出召回片段、相似度、来源文件和最终答案。

## 建议的元数据

```json
{
  "source": "04-leave-policy.md",
  "title": "休假与请假制度",
  "section": "病假",
  "version": "2026.1",
  "effective_date": "2026-01-01"
}
```

## 数据集设计

文档故意包含一些容易混淆的规则：

- 普通报销期限是 30 个自然日，差旅报销期限是返程后 15 个自然日。
- 国内酒店标准按城市类别和职级变化。
- 正式员工与试用期员工的远程办公规则不同。
- 病假、事假和年假的申请时限、证明材料不同。
- IT 服务台与安全事件的报告渠道不同。

这些差异可以用于观察文本切分、召回和引用是否准确。

## 使用限制

本数据集可自由用于个人学习、演示和测试。不要将其中制度用于现实组织。
