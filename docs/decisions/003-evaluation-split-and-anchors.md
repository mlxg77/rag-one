# ADR-003：回归/保留集分离与证据锚点

状态：已采用。

32 道旧题作为 regression，可反复用于错误分析。新增 15 道 holdout，版本候选冻结前不得读取其运行结果，避免把测试集当开发集。

多事实答案使用 evidence groups：同组内任一块可支持一个事实，全部组命中才算必要证据完整。

单纯保存 chunk ID 不能支持 chunk 参数实验，因为 `source:chunk-N` 的 N 会随 size/overlap 改变。为此额外冻结 `evidence-anchors.json`：每个必要事实由一个或多个语料原文片段标识，评估启动时把锚点解析到当前切分。这样所有参数共享同一事实定义，而不是共享已漂移的序号。

锚点是确定性规则，不是 LLM Judge；修改锚点属于修改标注，必须记录理由并重跑所有对照。
