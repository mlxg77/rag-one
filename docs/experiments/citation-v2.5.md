# v2.5 生成与引用质量实验

## 1. 目标与口径

本实验只调整生成 Prompt 和引用结构校验，不调整 Chunk、Embedding、BM25、RRF、Reranker、Top-K 或索引。

人工评审指标：

- 答案正确率：问题要求的关键事实是否完整且正确；
- 严格引用准确率：整道答案中的所有引用是否直接支持对应陈述；
- 引用块级支持率：直接支持答案的引用块数 / 全部引用块数；
- 拒答准确率：拒答或“资料未规定”的判断是否正确；
- 幻觉：是否出现资料不支持或与资料冲突的事实。

冻结门槛为答案正确率 ≥90%、严格引用准确率 ≥90%、拒答准确率 ≥90%、幻觉为 0。

## 2. C0 与 C1

### C0：历史基线

- 链路：E4 `hybrid_rerank`；
- Prompt：v2.0 历史 Prompt；
- Regression：严格引用准确率 79.3%（23/29），引用块级支持率 86.1%（62/72）；
- 主要错误：模型把 Top-5 中主题相关但未直接用于结论的块一起标入。

### C1：最少直接引用

版本：`v2.5-c1-minimal-citations`。

C1 增加资料不可信边界、最少直接引用、引用编号校验和完全拒答不带引用。32 题 Regression 已完整运行，检索指标为 100%，但 q09、q11、q12、q13、q19 在已有证据时错误拒答。

原 15 题 Holdout 在 C1 尚未通过完整 Regression 人工验收时被提前执行并消费。其检索指标为 100%，严格答案完整率仅 10/15（66.7%），不能作为通过结论。

## 3. C2—C4 迭代

| 候选 | Prompt 版本 | 主要变化 | 结果 |
|---|---|---|---|
| C2 | `v2.5-c2-evidence-first` | 逐项检查、组合分散证据、允许简单推导、部分回答 | 答案 81.25%、引用 100%、拒答 75%、幻觉 0 |
| C3 | `v2.5-c3-completeness-checklist` | 回答清单、同义规则/反例识别、未规定也是可回答结论 | q12 修复；出现矛盾式拒答和无关流程说明 |
| C4 | `v2.5-c4-focused-completeness` | 精确拒答边界、必要动作/禁止项、删除无关说明、逐事实直接引用 | 答案 90.63%、引用 100%、拒答 100%、幻觉 0 |

C4 Regression 人工失败项：

- q09：遗漏联系直属经理/人力资源处理；
- q16：遗漏紧急电话 6110；
- q17：遗漏不要回复、点击或下载。

其余 29 题通过，达到冻结门槛。自动指标保持 Recall@5、Evidence-group Recall@5 和 Complete-evidence@5 全部 100%，平均总耗时 2654.8 ms，P95 4795 ms。

## 4. 拒答结构校验修正

旧实现使用固定拒答句的子串判断，会把“资料无法确定金额，但资料规定应联系 HR [1]”误报为“完全拒答且带引用”。现改为仅当去除句号后的完整答案等于固定拒答句时，才判定为完全拒答。

C4 原始 JSON 使用旧判断显示 2 个“拒答带引用”；用修正后的结构校验离线复核为：完全拒答 1、拒答带引用 0。该修正只影响结构分类，不改写任何模型答案或人工质量结论。

## 5. 新盲测一次性终验

冻结 C4 后建立 `data/eval/blind-v2.5.jsonl`：20 题，其中 18 题有证据、2 题完全无资料。题目覆盖未参与 C1—C4 调优的入职、门禁、访客、考勤、费用边界、差旅例外、USB 和备份等主题。

运行纪律：只运行一次；结果查看后数据集即视为消费，不得根据逐题结果调整候选后重复宣称独立终验。

失败案例：

- b02：标注锚点块漏召回，但 FAQ 等价证据支持了正确答案；
- b10：把正好 5000 元错误判为需要财务负责人审批，且引用与答案相反；
- b17：第三个引用来自可疑邮件处置，不能直接支持 USB 插入后的报告动作；
- b19：引用健身补贴 FAQ 来支持生日礼金不存在，属于主题类比而非直接支持。

## 6. 结论

C4 在 Regression 上达到冻结门槛，但在新盲测上未达到严格引用 ≥90% 和幻觉为 0 的生产级要求。项目负责人接受 95% 的答案正确率，决定以“学习项目 / 内部演示完成版”结束 v2.5；这不改变终验数据，也不代表生产质量门槛已经通过。

b10、b17、b19 所代表的问题转入后续版本。如未来继续优化，只能把失败类型转入开发集或另建开发题；下一候选必须使用另一套全新盲测终验。现有原 Holdout 和本次 20 题盲测均不得再次作为独立终验。
