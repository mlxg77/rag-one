# v2.5 核心概念参考笔记

这是一份核对用参考，不代表学习者已经完成验收。

- BM25 的词频项让匹配词出现更多时得分上升，但通过饱和避免无限线性增长；IDF 提高稀有词权重；长度归一化避免长文仅因词多占优势。
- 向量相似度与 BM25 分数的量纲、范围和分布不同，直接相加会让某一路因数值尺度而非质量主导。RRF 只使用名次，先绕开分数标定问题。
- RRF 的 `k` 越小，榜首名次差异越重要；越大，不同名次间的贡献更平缓，共识候选更容易累积优势。
- Embedding 是双塔：问题与文档分开编码，可预计算文档，适合宽召回。Reranker 联合读取问题与候选，交互更充分但成本高，只适合小候选池。
- Any-hit 只证明“至少一个相关块”进入 Top-K。多事实答案必须按 evidence groups 检查每一项必要事实。
- regression 可反复暴露错误；holdout 用于最终泛化估计。用 holdout 调参会让它退化成新的开发集。
- 严格引用准确率按“整道回答的所有引用都直接支持”计题；引用块级精确率按“支持块数/全部引用块数”计块。前者对一次多引更敏感。
- 定位错误时先看必要证据是否召回，再看是否被排序挤出 Top-K，然后看送入 Prompt 的上下文，最后看答案是否正确使用证据。不要把所有错误都归因于模型。
