# rag-one 调优手册

本手册记录项目中哪些参数真正经过实验、哪些只是经验默认值，以及后续如何继续调优。目标是让每次修改都有可复现证据，避免把“改了配置”误称为“完成调优”。

## 1. 调优原则

一次有效调优至少需要：

1. 固定语料、评估集、模型和其余参数；
2. 一次只改变一个主要变量；
3. 调参只使用 regression，不能查看或利用 holdout 结果；
4. 同时记录质量、延迟、Token、索引规模和失败情况；
5. 保存原始 JSON、运行参数、索引版本和 Prompt 版本；
6. 只有对照数据稳定优于基线，才修改默认值；
7. 候选版本冻结后，使用未参与开发的 holdout 终验一次。

工程重构、异常校验和发布安全很重要，但它们属于工程优化，不等于检索或生成质量调优。

## 2. 当前链路与生效参数

```text
问题 ─┬→ 向量召回 Top-20 ─┐
      └→ BM25 召回 Top-20 ─┴→ RRF融合 Top-20 → Rerank → Top-5 → LLM
```

| 参数/策略 | 当前值 | 证据级别 |
|---|---|---|
| Chunk size / overlap | 800 / 150 | 有离线对照实验；无真实四模式全量实验 |
| 向量候选数 | 20 | 规划起点值，未单变量调优 |
| BM25 候选数 | 20 | 规划起点值，未单变量调优 |
| BM25 k1 / b | 1.5 / 0.75 | 经典默认值，未调优 |
| RRF k | 60 | 常用经验值，未调优 |
| Rerank 候选数 | 20 | 规划起点值，未调优 |
| 送入 LLM 的 Top-K | 5 | 产品经验值，未调优 |
| LLM temperature | 0.2 | 稳定性经验值，未做多值对照 |
| Embedding | BAAI/bge-m3 | 固定选择，未做模型对比 |
| Reranker | BAAI/bge-reranker-v2-m3 | 固定选择，未做模型对比 |
| LLM | Qwen/Qwen3-8B | 固定选择，未做模型对比 |
| Prompt | v2.5-c4-focused-completeness | C1—C4 已用 Regression 迭代；新盲测引用质量仍未达标 |

## 3. 已完成的调优

### 3.1 分块大小与重叠

v2.5 在固定语料和 regression 32 题上进行了 BM25 离线预检：

| 配置 | Chunk 数 | R@5 | MRR@10 | 完整证据@5 |
|---|---:|---:|---:|---:|
| 600/150 | 164 | 93.5% | 0.661 | 93.5% |
| 800/150 | 111 | 96.8% | **0.689** | 96.8% |
| 1000/150 | 90 | 96.8% | 0.635 | 96.8% |
| 800/80 | 109 | 96.8% | 0.673 | 96.8% |
| 800/220 | 128 | 96.8% | 0.678 | 96.8% |

结论：`800/150` 的 MRR@10 最高，继续作为冻结配置。`600/150` 同时降低召回与完整证据率，不采用。

边界：项目决定取消五套配置的真实 Embedding/Rerank 四模式实验。因此，只能说 `800/150` 是当前离线证据最好的工程选择，不能说它是完整链路的全局最优值。

历史实验还比较过 `400/150` 与 `800/150`。更细的 400 字符切分导致 chunk 数增加，来源级 Recall@5 从 100% 降到 93.5%，因此没有采用“小块一定更精确”的直觉结论。

### 3.2 检索架构

项目从单向量检索逐步增加 BM25、RRF 和 Reranker：

- BM25 补充关键词、编号和精确数字匹配；
- RRF 使用名次而非不同量纲的原始分数融合两路结果；
- Reranker 对融合候选做问题—文本交叉相关性排序；
- 最终 Top-5 控制上下文噪声和 Token 成本；
- Reranker 失败时回退 RRF，保障服务连续性。

v2 历史实验支持这条架构优于单路检索，但 `20/20/60/20/5` 这些内部数值没有完成系统搜索。因此，应称为“架构经过验证，参数仍以经验值为主”。

### 3.3 Prompt 与引用策略

v2.5 完成 C1—C4 四轮 Prompt 实验：

- C1：资料不可信边界、最少直接引用和统一拒答；
- C2：证据优先、组合分散证据、允许简单推导和部分回答；
- C3：回答完整性清单、同义场景识别、“未规定”也作为可回答结论；
- C4：收紧完全拒答边界、要求必要动作/禁止项、删除无关流程说明、逐事实直接引用；
- temperature 固定 0.2，关闭 Qwen thinking。

C4 Regression：答案 90.63%、严格引用 100%、拒答 100%、幻觉 0，满足冻结门槛。相比 C2，平均总耗时从 2607.1 ms 增至 2654.8 ms，增幅约 1.8%；平均 Prompt Token 从 2738.4 增至 3006.4，增幅约 9.8%。

拒答结构校验也由“包含固定拒答句”改为“完整答案等于固定拒答句”，避免把带有证据和后续动作的部分回答误判为完全拒答。

## 4. 新盲测揭示的问题

冻结的 `800/150 + hybrid_rerank + C4` 在新 20 题盲测上得到：

- Any-hit / Evidence-group / Complete-evidence@5：94.44%；
- 答案正确率：19/20，95%；
- 严格引用准确率：16/19，84.21%；
- 引用块级支持率：19/22，86.36%；
- 拒答准确率：2/2，100%；
- 幻觉：1。

失败模式：

| 类型 | 题目 | 表现 |
|---|---|---|
| 标注锚点漏召回 | b02 | 目标块未进 Top-5，但 FAQ 等价证据使答案仍正确 |
| 数值边界推理错误 | b10 | 正好 5000 元被错误归入超过 5000 元档 |
| 引用主题相关但不直接支持 | b17 | 用可疑邮件处置支持 USB 插入后的动作 |
| 无资料问题类比引用 | b19 | 用健身补贴 FAQ 支持生日礼金结论 |

诊断：C4 已显著缓解过度拒答，但数值边界理解和严格引用选择仍未稳定泛化。不能再把主要问题简单写成“只在生成层”或“检索始终 100%”。

注意：原 15 题 Holdout 和新 20 题盲测均已消费，不能用于继续调参后重复宣称独立终验。

## 5. 尚未真正调优的部分

以下配置目前合理但没有充分对照数据：

1. BM25 `k1` 和 `b`；
2. 向量与 BM25 的候选数量；
3. RRF `k`；
4. Rerank 候选数量；
5. LLM 上下文 Top-K；
6. LLM temperature；
7. Embedding、Reranker 和 LLM 模型；
8. 拒答阈值或基于 Rerank 分数的置信度策略；
9. 生成后的逐事实证据蕴含校验或引用后验验证。

这些值可以配置和修改，不代表已经调优。没有固定数据集、单变量对照与复现实验时，不应写“最优”。

## 6. 下一轮调优优先级

### P0：边界判断与引用直接支持性

只能使用 Regression 或新增开发题，不能使用两套已消费终验集调参。优先研究：

- 数值边界表达（小于、等于、超过、区间端点）的开发题；
- 对每个生成事实执行引用蕴含检查，不支持则删除该事实或改选证据；
- 无资料问题禁止用相邻福利、相邻制度做主题类比引用；
- 对附加建议设置更严格的直接证据要求，减少“核心答案正确、附加内容乱引”。

重点指标：边界题正确率、严格引用准确率、引用块级支持率和幻觉数。

### P1：上下文数量

在最佳 Prompt 固定后，比较 Top-K `3/5/8`。观察：

- Top-K 太小是否漏掉多证据；
- Top-K 太大是否增加模板噪声和乱引用；
- Prompt Token、延迟和费用变化。

### P2：候选与融合参数

依次做单变量实验，建议范围：

- 向量候选：10、20、30；
- BM25 候选：10、20、30；
- RRF k：20、60、100；
- Rerank 候选：10、20、30。

先看 Recall/完整证据，再看 MRR、延迟和 Rerank Token。召回没有明显改善时，不应为更大的候选池支付额外成本。

### P3：BM25与模型选择

只有在前述高收益项完成后，再考虑：

- BM25 k1/b 小范围网格；
- 不同 Embedding 模型；
- 不同 Reranker；
- 不同 LLM 的正确率、引用表现、延迟和成本。

模型对比成本较高，且会同时改变多个行为，应最后进行。

## 7. 标准实验模板

每次实验至少记录：

```text
实验编号：
假设：
唯一变量：
基线值 / 候选值：
固定项：语料、数据集、索引版本、模型、Prompt版本
数据集：仅 regression / 新开发集
质量指标：Recall@5、MRR@10、完整证据、答案正确率、引用准确率、拒答率、幻觉率
成本指标：P50/P95延迟、Prompt Token、Rerank Token、索引大小
结果：
结论：保留 / 回滚 / 继续观察
原始产物路径：
```

如果实验结果只改善单题、总体指标不变，或以明显成本换取微小收益，应记录但不立即修改默认值。

## 8. 当前最终判断

- 分块：`800/150` 有离线证据支持，暂时保留；
- 检索：混合检索加重排有效，但新盲测完整证据为 94.44%，不能宣称始终 100%；
- 生成：C4 已显著改善拒答与完整性，Regression 达标；
- 当前最值得投入的调优方向：数值边界判断和逐事实引用直接支持性；
- 当前版本已按学习项目 / 内部演示目标完结；引用和边界判断遗留问题转入后续版本，不作生产质量承诺。
