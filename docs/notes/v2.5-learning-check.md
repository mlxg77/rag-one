## 作答区

1. BM25 的 tf、idf 和长度归一化分别解决什么问题？
2. 为什么向量分数与 BM25 分数不能直接相加？
3. RRF 的 k 改大或改小会发生什么？
4. 召回候选数、融合候选数和最终 Top-K 分别控制什么？
5. Reranker 与 Embedding 检索模型的计算方式有什么区别？
6. q20 在 vector 链路中属于召回错误还是生成错误？
7. q12 为什么属于“证据已经召回但生成失败”？
8. 为什么 Recall@5=100% 仍不能证明多证据问题已经完整召回？
9. 为什么删除旧集合后再重命名 staging 不是真正的安全切换？
10. manifest 如何保证向量与 BM25 属于同一版本？
11. regression set 和 holdout set 为什么不能混用？
12. 严格引用准确率与引用块级精确率有什么区别？
13. 当前 chunk 参数的选择证据是什么？
14. E4 的质量收益是否值得额外延迟和 token 成本？
15. 如果 v2.5 仍有错误，如何判断应修检索、排序、上下文还是生成？
